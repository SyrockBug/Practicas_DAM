========================
      DESCRIPCIÓN
========================

Este programa fue creado como tarea para la asignatura de Programación usando JDK 17, JavaFX 17 y Ant.

Se trata de una reimaginación a pequeña escala del famoso juego Buscaminas. En este caso se ha optado
por darle una temática naval mediante el uso de CSS.

Se adjunta tanto el proyecto de Netbeans como el programa preparado para su distribución en la carpeta
"dist", para su ejecución se debe usar el archivo "Buscaminas.bat"
