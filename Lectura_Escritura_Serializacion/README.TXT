========================
       DESCIPCIÓN
========================

El programa fue creado como tarea práctica de la asignatura de programación.
Realiza la lectura secuencial de un fichero de texto plano que almacena la información del profesorado y sus módulos,
se almacena la información de cada uno en un objeto "Profesor" y estos a su vez en un objeto "Instituto" para que, 
una vez leidos todos los profesores, se cree un archivo de texto plano que representa al profesorado del instituto
con el formato especificado en la tarea.

Finalmente se realiza la serialización de todos los objetos para poder almacenarlos en un archivo binaro.
El programa mantinene al usuario informado del proceso por consola durante su ejecución.

Se adjunta el proyecto completo en Netbeans asi como la carpeta "dist" en la que se encuentra el programa preparado
para su distribución y ejecución. Se debe usar el archivo "Run.bat" para su ejecución.

El proyecto ha sido realizado usando el JDK 17 con el compilador Ant.
